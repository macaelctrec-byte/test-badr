# 🤖 دليل تشغيل وربط بوت إدارة الطلبات عبر Telegram (متجر مكة)

يقدم هذا الدليل خطوات ربط متجر مكة مع بوت تليجرام باستخدام **Google Apps Script** بشكل مجاني وآمن بنسبة 100% دون الحاجة لسيرفر خارجي أو كشف توكن البوت للعملاء.

---

## 🌟 مميزات النظام:
1. **إشعار فوري عند كل طلب جديد:** تفاصيل العميل، العنوان، المنتجات، الإجمالي، وصورة إثبات التحويل (فودافون كاش / إنستاباي).
2. **أزرار تحكم تفاعلية مباشرة داخل Telegram:**
   - `[ ✅ تأكيد الدفع ]`: يعتمد الدفع فورياً ويحدّث قاعدة البيانات وتتبع العميل.
   - `[ ❌ رفض الدفع ]`: يعرض قائمة أسباب (المبلغ غير صحيح، إثبات الدفع غير واضح، لم يتم استلام التحويل، إلخ) أو إدخال سبب مخصص.
   - `[ 📦 تفاصيل الطلب ]`: يعرض كافة تفاصيل الطلب مع رابط مباشر لفتحه في لوحة التحكم.
3. **دورة حياة الطلب المتسلسلة من تليجرام:**
   - `[ 📦 بدء تجهيز الطلب ]`
   - `[ 📦 تم تجهيز الطلب ]`
   - `[ 🚚 تم الشحن ]`
   - `[ ✅ تم التسليم ]`
4. **تزامن لحظي مع قاعدة البيانات وصفحة تتبع العميل:**
   - عند أي إجراء من Telegram، تتحدث صفحة تتبع الطلب الخاصة بالعميل فوراً بدون إعادة تحميل الصفحة.
   - عند رفض الدفع، يظهر للعميل سبب الرفض مع زر "إعادة رفع إثبات الدفع".
5. **مزامنة عكسية (Reverse Sync):**
   - عند تعديل الحالة من لوحة تحكم الويب، يصل إشعار تلقائي إلى Telegram.

---

## 🚀 خطوات الإعداد (خلال 3 دقائق):

### 1. إنشاء بوت Telegram:
1. افتح تطبيق Telegram وابحث عن **`@BotFather`**.
2. أرسل الأمر: `/newbot`
3. أدخل اسماً للبوت (مثال: `بوت متجر مكة`).
4. أدخل اسم مستخدم للبوت ينتهي بـ bot (مثال: `MaccaStoreOrdersBot`).
5. سيعطيك BotFather **توكن البوت (Bot Token)**، انسخه واحتفظ به.

### 2. معرفة الـ Chat ID الخاص بك:
1. في Telegram ابحث عن **`@userinfobot`** أو **`@raw_data_bot`**.
2. اضغط Start وسيعطيك رقم الـ **`Id`** الخاص بك (مثال: `123456789`).

---

### 3. إعداد Google Apps Script:
1. ادخل على [script.google.com](https://script.google.com).
2. اضغط على **مشروع جديد (New Project)**.
3. افتح ملف `Code.gs`، واحذف ما بداخله والصق محتوى ملف `google-apps-script/Code.gs` الموجود هنا.
4. اذهب إلى **إعدادات المشروع (Project Settings)** من القائمة الجانبية (رمز الترس ⚙️).
5. انزل لأسفل إلى **خصائص البرنامج النصي (Script Properties)** واضغط **إضافة خاصية (Add property)**، وأضف الخصائص التالية:
   - `TELEGRAM_BOT_TOKEN`: توكن البوت الذي حصلت عليه من BotFather.
   - `ADMIN_CHAT_ID`: الـ Chat ID الخاص بك.
   - `BACKEND_API_URL`: رابط السيرفر أو رابط متجرك (مثال: `https://macca3.shop`).
   - `API_SECRET_KEY`: `macca_telegram_secret_key_2026`
   - `STORE_URL`: `https://macca3.shop`
6. اضغط **حفظ الخصائص (Save properties)**.

---

### 4. نشر المشروع (Deploy):
1. اضغط على زر **نشر (Deploy)** بالأعلى ثم **نشر جديد (New deployment)**.
2. اختر نوع النشر: **تطبيق ويب (Web app)**.
3. اضبط الإعدادات:
   - **الوصف (Description):** `Macca Orders Webhook`
   - **تنفيذ كـ (Execute as):** `أنا (Me)`
   - **من يمكنه الوصول (Who has access):** `الجميع (Anyone)`
4. اضغط **نشر (Deploy)** وامنح الصلاحيات المطلوبة.
5. انسخ **رابط تطبيق الويب (Web app URL)** الناتج.

---

### 5. تفعيل الـ Webhook بنقرة واحدة:
- في محرر Google Apps Script، اختر الدالة **`setTelegramWebhook`** من شريط الدوال العلوي واضغط **تشغيل (Run)**.
- أو افتح هذا الرابط في المتصفح بعد وضع التوكن ورابط الـ Web App:
```
https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=<YOUR_WEB_APP_URL>
```
ستظهر لك رسالة:
`{"ok":true,"result":true,"description":"Webhook was set"}`
